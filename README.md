# Football Legends 🏆

A modern web application showcasing the greatest football (soccer) players of all time with detailed statistics, career highlights, and video content.

## 🚀 Features

- **Player Profiles**: Comprehensive information about legendary football players
- **Career Statistics**: Detailed stats including goals, assists, and achievements
- **Timeline**: Interactive career highlights showing major milestones
- **Video Highlights**: Embedded YouTube videos of best moments
- **Fun Facts**: Interesting trivia and achievements
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Dark Theme**: Eye-friendly dark theme with gold accents

## 💻 How to Run

### Local Development

```bash
# Start a simple HTTP server
python3 -m http.server 8000

# Open in browser
# http://localhost:8000
```

### Using Node.js (if available)

```bash
npx http-server
```
