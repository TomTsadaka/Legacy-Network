# The Chamber

אב-טיפוס ל-RTS שבו שתי חיות מתמזגות ליצור היברידי אחד בזמן ריצה — ברוח Impossible Creatures (2003).

> **מצב נוכחי:** שלב 1+2 — שלד פרויקט ומערכת המיזוג.
> מכוון ל-**UE 5.8**. הקוד **לא קומפל עדיין** — נכתב בסביבה ללא התקנת Unreal.

---

## 1. התקנת Unreal Engine

המנוע **חינם**. תמלוגים של 5% חלים רק על הכנסה מעל מיליון דולר למוצר.

### Windows

1. `unrealengine.com` → פתח חשבון Epic Games.
2. הורד והתקן את **Epic Games Launcher**.
3. בלאנצ'ר: לשונית **Unreal Engine** → **Library** → `+` → בחר גרסת 5.x.
4. התקן **Visual Studio 2022 Community** עם ה-workload **"Game development with C++"**.
   בלי זה הפרויקט לא יתקמפל.
5. *(Windows בלבד)* **UE 5.8 דורש MSVC חדש יותר מ-5.7.** אם הבנייה נכשלת מיד עם שגיאות toolchain —
   עדכן את כלי הבנייה של Visual Studio לפני שאתה מחפש באג בקוד. זו התקלה הנפוצה ביותר
   במעבר ל-5.8.

### macOS

המנוע עובד על מאק, כולל Apple Silicon (M1 ומעלה) באופן נייטיבי.

1. אותם שלבים 1–3 כמו ב-Windows.
2. **אל תוריד את Xcode מה-App Store.** ה-App Store נותן תמיד את הגרסה העדכנית
   ביותר, ולפי התיעוד של Epic **Xcode 26.4 אינו תואם ל-Unreal Engine**.
   הורד גרסה ספציפית מ-[Apple Developer Downloads](https://developer.apple.com/download/all/)
   (נדרש Apple ID חינמי) — חפש **Xcode 26.1.1**, הגרסה ש-Epic ממליצה עליה ל-5.8.
3. צריך את **Xcode המלא**, לא רק Command Line Tools. אנריל משתמש בו גם לייצור
   פרויקט ה-Xcode וגם לקומפילציה.
4. אחרי ההתקנה, הרץ בטרמינל:
   ```bash
   sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
   sudo xcodebuild -license accept
   xcodebuild -runFirstLaunch
   xcodebuild -version      # אימות: צריך להראות 26.1.1
   ```

**גרסת macOS:** המינימום לעורך הוא 13.x. עבור Shader Model 6 נדרש 15.x ומעלה.
השילוב שאפיק ממליצה עליו ל-5.8 הוא **macOS 15 (Sequoia) + Xcode 26.1.1**.
יש דיווחים בפורומים על כשלי קומפילציה בשילוב macOS 26 עם Xcode 26.x.
בדוק מה יש לך עם `sw_vers`.

**מגבלות שחשוב להכיר לפני שמתחייבים למאק:**

| נושא | מצב במאק |
|---|---|
| עורך ופיתוח | עובד מלא |
| Nanite / Lumen | נתמכים דרך Metal, עם פערי ביצועים מול Windows |
| **בניית גרסת Windows** | **בלתי אפשרי ממאק** |

השורה האחרונה היא הקריטית: משחקי RTS נמכרים כמעט אך ורק ל-Windows. ממאק אפשר לארוז ל-macOS, ל-iOS ול-Android בלבד. אם המשחק מיועד ל-Steam, תצטרך גישה למכונת Windows כלשהי לבניית הגרסה הסופית — שלך, או מכונת בנייה.

### דרישות חומרה

| רכיב | מינימום | מומלץ |
|---|---|---|
| RAM | 16GB | 32GB |
| דיסק | 100GB+ פנוי | SSD |
| GPU | כרטיס ייעודי | RTX class / Apple Silicon Pro ומעלה |

## 2. פתיחת הפרויקט

הפרויקט מכוון ל-**UE 5.8** (`BuildSettingsVersion.V7`, `EngineIncludeOrderVersion.Unreal5_8`).
אם תעבור גרסה, עדכן את שני קבצי ה-`Target.cs` ואת `EngineAssociation` ב-`.uproject` יחד.

הפרויקט מפעיל את תוסף המנוע **SkeletalMerging** — מערכת המיזוג נשענת עליו.

ואז:

- **Windows** — קליק ימני על ה-`.uproject` → *Generate Visual Studio project files* → פתח את ה-`.sln` → Build.
- **macOS** — קליק ימני על ה-`.uproject` → *Services* → *Generate Xcode project files* → פתח ובנה.

## 3. ארכיטקטורה

### הכלל שהכל נשען עליו

**שלד קנוני אחד לכל החיות בפרויקט.** אותם שמות עצמות, אותה היררכיה. ההבדל בין פיל לצ'יטה מתבטא ב-`BoneScales` ובמש — **לעולם לא ברִיג אחר**.

אם חיה אחת תפר את הכלל הזה, היא לא תוכל להתמזג עם אף חיה אחרת. זה מה שהופך את הוספת החיה ה-40 למשימת אמנות במקום משימת הנדסה.

### הקבצים

| קובץ | תפקיד |
|---|---|
| `CreatureTypes.h` | `FCreatureStats` — פרופיל קרב/תנועה. `FCreatureFusionWeights` — כמה כל הורה תורם לכל סטט. **זה כפתור האיזון המרכזי של המשחק.** |
| `AnimalDataAsset.h/cpp` | חיה אחת: שני משים, סטטים, יכולות לכל חצי, סקאלות עצמות. |
| `CreatureDefinition.h/cpp` | תוצאת המיזוג — כל מה שצריך כדי לרפרש יצור אחד. |
| `CreatureFusionLibrary.h/cpp` | **הלב.** מיזוג הסטטים ומיזוג המשים דרך `USkeletalMergingLibrary::MergeMeshes`. |
| `CreatureMeshCache.h/cpp` | מטמון משים ממוזגים לפי צירוף. גם מונע איסוף זבל של משים חיים. |
| `CreaturePawn.h/cpp` | היצור בעולם. מבצע את המיזוג ומחיל סטטים על תנועה, קוליז'ן ובריאות. |
| `CreatureAnimInstance.h/cpp` | מחזיק את סקאלות העצמות עבור גרף האנימציה. |

### חוקי המיזוג (ברירת מחדל)

החצי **הקדמי** הוא הצד העסקי — ראש, לסתות, עיניים. לכן הוא שולט בהתקפה ובראייה.
החצי **האחורי** הוא המנוע — אגן, רגליים אחוריות, זנב. לכן הוא שולט בתנועה.

| סטט | משקל החצי הקדמי |
|---|---|
| נזק / קצב התקפה | 0.8 |
| ראייה | 0.9 |
| בריאות / שריון / גודל | 0.5 |
| **מהירות תנועה** | **0.25** |

זו הסיבה ש"פיל מקדימה + צ'יטה מאחורה" מרגיש שונה מההפך. **כוונן את המספרים האלה — זה כיוונון תחושת המשחק כולה.**

## 4. מה שנשאר לעשות בעורך

הקוד מוכן, אבל שלושה דברים חייבים להיעשות ידנית בעורך — אי אפשר לייצר אותם מקוד:

1. **שלד מאסטר + סט אנימציות** (idle / walk / run / attack / death).
2. **Anim Blueprint** שיורש מ-`UCreatureAnimInstance`, עם צומת **Transform (Modify) Bone** לכל עצם שמשנים, שקורא מ-`GetBoneScale()`.
   *למה זה חייב להיות בגרף:* האנימציה דורסת את טרנספורמי העצמות בכל פריים. סקאלה שמוחלת פעם אחת בלידה פשוט תימחק.
3. **נכסי `UAnimalDataAsset`** תחת `/Game/Creatures/Animals` — שתי חיות מספיקות כדי להוכיח את המנגנון.

### המבחן של שלב 2

שתי חיות, ארבעה צירופים, היצור נוצר והולך על המפה. אם זה כיף להתעסק עם זה — יש משחק. אם לא — עדיף לדעת עכשיו.

## 5. תקלות אפשריות בקומפילציה הראשונה

הקוד לא נבדק מול קומפיילר. אלה המקומות הסבירים לבעיה, לפי סדר:

| תסמין | סיבה וטיפול |
|---|---|
| שגיאות toolchain מיד בתחילת הבנייה (Windows) | MSVC ישן מדי ל-5.8. עדכן את כלי הבנייה של Visual Studio. |
| שגיאות `Platform Mac` בתחילת הבנייה (macOS) | אי-התאמה בין גרסת Xcode לגרסת המנוע. אמת עם `xcodebuild -version`. |
| `xcrun: error: unable to find utility` (macOS) | `xcode-select` מצביע על Command Line Tools במקום על Xcode המלא. הרץ את הפקודה `xcode-select -s` מסעיף 1. |
| `Plugin 'SkeletalMerging' not found` | התוסף נקרא אחרת בגרסה שלך — הסר את הבלוק `Plugins` מה-`.uproject` והשאר רק את התלות ב-`Build.cs`. |
| `Cannot open include file: 'SkeletalMergingLibrary.h'` | המודול `SkeletalMerging` לא נטען. ודא שהוא מופיע ב-`TheChamber.Build.cs`. |
| שגיאות UHT על `TObjectPtr` / `const` | חתימה שהשתנתה ב-5.8. שלח לי את השגיאה. |

## 6. הערה משפטית

Impossible Creatures הוא קניין רוחני של Relic / THQ Nordic. מנגנוני משחק אינם מוגנים בזכויות יוצרים, ולכן בניית RTS עם מיזוג חיות היא לגיטימית לחלוטין — רק בלי השם, בלי הנכסים ובלי עיצובי היצורים המקוריים.
